# ssc-lottery-notes

## 项目简介

本仓库用于归档和发布多个独立的 HTML 页面，主要收录与彩票相关的信息整理、数据记录及分析笔记。页面以静态 HTML 形式保存，便于直接浏览与离线查阅。

仓库内容不针对任何特定网站或平台，仅作为个人笔记与资料存档使用。

## 目录说明

```
.
├── index.html          # 入口导航页
├── pages/              # 存放各个独立 HTML 页面
│   ├── note-001.html
│   ├── note-002.html
│   └── ...
└── assets/             # 页面共用的样式、脚本、图片等资源
    ├── style.css
    └── script.js
```

- `pages/` 目录下每个 HTML 文件为一篇独立的笔记或数据归档页面。
- `assets/` 目录存放页面共用的资源文件，便于统一维护。

## 页面归档说明

- 每个页面均为独立完整的 HTML 文件，可直接在浏览器中打开。
- 页面内容可能包含文字、表格、图表等形式，用于记录特定主题下的信息。
- 归档内容不保证实时更新，部分数据可能仅代表记录时的状态。
